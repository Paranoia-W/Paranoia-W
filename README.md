## 👋 关于我

你好，我是 **Paranoia-W**。

我专注于自动驾驶规划、ROS 机器人系统与高精地图相关开发，喜欢把复杂的路径问题拆成清晰、可运行、可视化的工程模块。

- 🚘 正在探索：路径规划、车道拓扑与路线优化
- 🗺️ 经常打交道：OpenDRIVE、高精地图与坐标转换
- 🧭 喜欢的反馈方式：让算法在 RViz 中“说话”
- 🛠️ 开发信条：先跑通，再看懂，最后让它更优雅
